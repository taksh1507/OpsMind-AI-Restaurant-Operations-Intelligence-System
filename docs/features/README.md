# Feature Guides

One page per major feature. A feature is documented here **after** it ships and
passes its smoke test — so everything on this list is real and usable today.

For what's coming next, see the [Roadmap](../roadmap.md).

## Shipped

- **[Menu Management](menu-management.md)** — add, edit, categorize, and hide
  menu items; record ingredient costs for margin analysis. *(Phase 1)*
- **[Staff Accounts & Roles](staff-accounts.md)** — create logins for your team,
  assign Owner/Manager/Staff roles, one-time temporary passwords, forced
  password change on first login. *(Phase 2)*
- **[AI & Model Preferences](ai-preferences.md)** — choose the Claude model,
  toggle AI insights and weather signals, set default city and timezone.
  *(Phase 3)*
- **[AI Usage & Limits](ai-usage-metering.md)** — see how much AI your
  restaurant uses, with a monthly cap that keeps AI spend under control.
  *(Phase 4)*

## How to read these

Each page has the same layout:

- **What it does** — in plain language.
- **How to use it** — step by step, from the app.
- **Who can use it** — which roles have access.
- **Security notes** — what protects your data for this feature.

If a page describes something you can't find in the app, that's a documentation
bug — please flag it (see the note at the bottom of the [docs index](../README.md)).
